# Examples

Three complete experiments, each generated by `psychopy-cli spec new <template>`.
They are the fastest way to see what a spec looks like at full size.

| File | What it demonstrates |
| --- | --- |
| `minimal.spec.json` | one routine, one loop, one keyboard component |
| `stroop.spec.json` | colour-valued conditions, correctness scoring, code-driven feedback |
| `flanker.spec.json` | frame-level stimulus timing, string conditions, accuracy tracking |

Run them from the repository root:

```bash
psychopy-cli spec validate examples/stroop.spec.json
psychopy-cli build examples/stroop.spec.json -o build/stroop --script
psychopy-cli run examples/stroop.spec.json --simulate -o runs/rehearsal
psychopy-cli run examples/stroop.spec.json --participant p01
psychopy-cli data summarize runs/<the newest run>/data.csv --group-by condition
```

`run` without `--simulate` opens a window and waits for keys. With
`--auto-response` it answers every keyboard component itself, which is how the
test suite smokes the runtime without a participant.
